# One Small Win starter files

These files are a teaching copy of the checklist built in the course. They are not a finished Expo project. `create-expo-app` creates `package.json`, the install, and the current template. After that, copy this `src` folder over the template's `src` folder.

Checked against Expo's start-developing page on 8 November 2026, which places routes in `src/app`. If your template uses `app/` at the project root instead, put the route files there and keep `wins.ts` somewhere the imports can reach.

`app.example.onesmallwin` is a placeholder. Replace `example` before you create the App Store record. The bundle identifier cannot be changed after you upload a build.

The iOS build, Expo Go, and App Store steps were not run in the environment that published this course. The browser lesson on the course page uses the same 120-character limit and was tested there.

Do not commit Apple passwords, App Store Connect API keys, or `.p8` key files.
