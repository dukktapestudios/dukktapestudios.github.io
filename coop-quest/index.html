Rooster Rumble: Coop Quest

A small flock game set in Hatchwick.

How to wander

Pick a first bird, then walk the lane with the arrow keys or WASD. On a phone, use the pad. The A button talks, checks the feed bin, and confirms. B closes a list. Tall clover and the thicket can hide stray birds. Fight, toss a feed sack, call another bird, or slip away. The barn mends the flock. Save stores this coop in the browser.
