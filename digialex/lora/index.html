DigiAlex crash course · example rural property

Build a LoRa mesh for off-grid text & sensors

Beginner path for an example rural property: a house, a barn, and an outbuilding on open ground. This layout is fictional and is not a real address. When cell and internet fail, a cheap 915 MHz Meshtastic mesh keeps short texts and sensor telemetry hopping around the property. It complements a separate HF NVIS radio plan. It does not replace one.

US915 · Meshtastic · Heltec V3 · Phase 1 ≈ $350

★Start here (5-minute plan)

  1. Buy 2× Heltec WiFi LoRa 32 V3 (915 MHz) + one LiPo each. Flash Meshtastic, set region US, prove house↔handheld text.
  2. Weatherproof barn + coop (IP65 box, external 5 dBi antenna, solar). Add a cheap BME280 on the coop for temp/humidity.

  4. MQTT into DigiAlex when Wi‑Fi exists. Keep a separate HF NVIS radio and a wire antenna as the regional layer.

01What a LoRa mesh is

It is

  • Small radios talking on 902–928 MHz (US ISM) with long range and tiny power
  • Nodes that relay short encrypted texts + telemetry so the barn hears the house even if they can’t both see each other
  • Phone apps (BLE) so you text the mesh while walking the yard — no cell tower required

It isn’t

  • Wi‑Fi or a replacement for Starlink / fiber
  • A statewide radio net (that’s HF NVIS)
  • Something you buy once as a EU 868 board — wrong band for Illinois

Firmware we use: Meshtastic — open source, Heltec/T‑Beam support, private channels, telemetry, MQTT. Stick with it unless you have a specific reason not to.

02Why it fits the off-grid goal

  • No cell / no internet? Texts and coop temps still hop house↔barn↔coop.
  • Cheap solar nodes (~$65–80 outdoors) sit for months on a 5–10 W panel + LiPo.
  • DigiAlex stays local-first: sensors → mesh packet → optional MQTT → your dashboard — not a vendor cloud.
  • Part 15 LoRa: no ham license for this layer (antenna ≤6 dBi or cut power).
Think of LoRa as the property LAN. HF NVIS is the regional WAN. Use both.

05Step-by-step build order

  1. Prove the link. Flash 2× Heltec V3 915 with Meshtastic web flasher. Region US. Create a private encrypted channel. Send a text house↔second board. Never TX without an antenna attached.
  2. Weatherproof barn + coop. IP65 box, cable glands, external 5 dBi omni clear of metal. South-facing solar. Add BME280 on coop I²C; enable Environment Telemetry.
  3. Raise house antenna + walk-test. Mount H1 high. Walk the fence with phone BLE + handheld; note SNR collapses. Add edge solar only where needed.
  4. Edge solar (E1). Property high point toward the longest sightline on the example lot.
  5. MQTT → DigiAlex. On the house hub, enable MQTT JSON uplink to a local broker when Wi‑Fi is up. DigiAlex ingests telemetry. When internet is down, phone + mesh still work locally.
  6. Keep HF separate. Practice NVIS on a separate HF radio. Don’t send outbuilding temperatures over HF.

06Meshtastic setup basics

  1. Open meshtastic.org → web flasher → pick Heltec V3 / T‑Beam → flash over USB.
  2. Install Meshtastic Android or iOS app. Connect over BLE (or serial).
  3. Set LoRa region = US. Confirm hardware is 915 MHz (not 868/433).
  4. Create a private channel with a strong PSK. Share it only with the nodes you control.
  5. Device role on a spread-out rural lot: almost everything = CLIENT. Avoid roof ROUTER/REPEATER unless you intend to serve a wide public mesh.
  6. Name nodes clearly: H1-House, B1-Barn, C1-Coop, E1-Edge, HH-TBeam.

07How sensors feed the mesh (and DigiAlex)

  1. Wire a supported I²C sensor (e.g. BME280 temp/humidity/pressure) to the coop/barn Heltec.
  2. Enable Environment Telemetry in Meshtastic (default often ~30 min — shorten carefully; airtime matters).
  3. Telemetry floods the local mesh with no internet.
  4. When internet exists: house hub MQTT JSON → local broker → DigiAlex ingests type: telemetry (temp, humidity, battery…).
  5. When internet is down: phone still sees nodes over BLE/LoRa; DigiAlex can later read a LAN broker or serial/BLE bridge.
Path: sensors → Meshtastic packet → (optional MQTT) → DigiAlex — never “sensor → vendor cloud.”

Use both layers. Don’t stretch LoRa across Illinois. Don’t burn HF airtime on coop temperature every half hour.

✓Checklist before you order

  • Boards are explicitly 915 MHz / US915
  • One handheld T‑Beam for walk-tests
  • IP65 boxes + 5 dBi antennas + short pigtails
  • 5–10 W solar for outdoor posts
  • BME280 for coop telemetry
  • Plan for MQTT only after Phase 1 RF works
Safety: no TX without antenna; roof/mast = fall + power-line hazard; encrypt the private channel; don’t put family keys on an unattended public repeater.
