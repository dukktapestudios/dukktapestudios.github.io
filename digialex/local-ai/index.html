Standalone offline AI

Run your own AI on your own computer — no cloud, no subscription, works when the internet is down. ← All guides

1 · What a standalone AI actually is

Two pieces: a model file (the "brain," a few GB download) and runner software that loads it and answers you. Download once; after that everything runs locally — your prompts never leave the machine.

2 · The software: Ollama (free)

Ollama is the easiest route on Windows, macOS, or Linux. One installer, one command to pull a model, and it automatically exposes a local API at http://localhost:11434 that other programs can call.

3 · Minimums

  • RAM: 8 GB bare minimum (3B-class models); 16 GB is comfortable.
  • Storage: ~10 GB free (SSD strongly preferred); 50+ GB if you'll collect several models.
  • GPU: optional. CPU-only works for small models, just slower. Any GPU with ~4 GB+ VRAM speeds things up a lot.
  • OS: Windows 10/11, macOS 12+, or Linux.

Rule of thumb: a model needs roughly its file size in memory, plus ~1–2 GB headroom. If it fits in GPU VRAM it's fast; if it spills to system RAM it slows down.

5 · Goal to shoot for

For something that feels like a strong everyday assistant: 24 GB VRAM + 32–64 GB system RAM + 1 TB SSD, running a ~30B model (e.g. Qwen 32B / Gemma 27B class). It still won't match the very best cloud models on hard reasoning, but it handles real work offline. Start small first — you can always upgrade the GPU later.

6 · Step by step

  1. Install Ollama from ollama.com/download and run the installer.
  2. Open a terminal (PowerShell) and pull a small model:
    ollama pull llama3.2:3b
  3. Chat with it:
    ollama run llama3.2:3b
    Type a question; /bye to exit. Unplug the internet and try again — it still works.
  4. Run it headless for agent jobs (the background service starts automatically; or):
    ollama serve
  5. Call it from scripts:
    curl http://localhost:11434/api/generate -d "{\"model\":\"llama3.2:3b\",\"prompt\":\"Summarize today's coop log\",\"stream\":false}"
  6. Check what's loaded: ollama list · ollama ps

7 · Plugging into DigiAlex

  • Agents: point DigiAlex agents at http://localhost:11434 (Ollama also offers an OpenAI-compatible endpoint at /v1) instead of a cloud API — summaries, drafts, and routine jobs run locally.
  • Monitoring: sensor readings (propane, well, coop temps) go to a small script that asks the local model to flag anomalies and write a plain-English status.
  • LoRa mesh: mesh messages land on the house hub via MQTT → script → local model → short reply back over the mesh. AI help with cell and internet both down.
  • To share it with other machines on your LAN, set OLLAMA_HOST=0.0.0.0 — keep it off the public internet.

8 · Rough cost

  • $0 — Ollama and models are free; runs on hardware you already have.
  • ~$300–1,500 used — a bigger GPU later (12–24 GB VRAM) for mid-range/high-end tiers.
  • Power: a few cents per hour of heavy use.
