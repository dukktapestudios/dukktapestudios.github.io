Library-Style Private Home Computer

Build a calmer Windows 11 browsing workspace: start clean, keep your personal life separate, and reduce the ways websites recognize you. A gentle, step-by-step guide to reboot-to-restore, privacy-focused browsers, and the limits that still matter.

Beginner · Windows 11 · Dedicated PC preferred · No perfect anonymity

Printout: interactive checklist ticks are not a permanent record.

Read this before changing anything

Reboot-to-restore rolls back protected drives, not just one user. New files can disappear at the next restart. Back up first. Also, Reboot Restore Rx Freeware is now retired; the current official alternatives described here are paid products or limited trials. No purchase or installation is required just to learn from this page.

01A fresh start is useful. It is not invisibility.

A library-style PC returns to a known, clean starting point after a restart. You can use it for ordinary reading and research without collecting months of old downloads, browser cookies, and settings. Here, “wipe on reboot” means discard changes on protected drives and restore the baseline—not erase the whole computer or securely destroy every recoverable trace.

A baseline is the starting state you choose: Windows updated, a local browsing user ready, and a privacy-focused browser installed. Think of a reusable desk that is reset after every visitor. You must deliberately open maintenance time to improve that starting state.

Cookies

A website's little memory

A cookie is a small piece of information a site stores in your browser. Some keep you signed in or remember a shopping basket. Others help link visits. Removing cookies helps with this memory, but it does not delete a website's own records.

Fingerprinting

Recognition without a saved cookie

A script can combine things such as your screen size, fonts, browser features, and graphics behavior. That combination can make your browser recognizable. Resetting Windows does not change all of those characteristics. A fingerprint-resistant browser tries to make you blend in, or makes those measurements less consistent.

IP address

Your connection's return address

A site normally sees the public IP address your traffic comes from. It can suggest a network and approximate location; it is not necessarily your name or exact street address. Several people can share an address. A reboot does not reliably give you a different public IP.

Logins

The simplest way to identify yourself

If you sign into a personal account, that service knows the account—even if cookies were cleared first and the connection uses Tor or a VPN.

Read EFF’s explanation of cookies and fingerprints, Mullvad’s explanation of IP addresses, and Tor’s limits on anonymity.

Three different jobs

A local user separates everyday activity. Reboot-to-restore resets local changes. A privacy browser and Tor or a VPN reduce different kinds of online tracking. None replaces the others.

02Make a separate local Windows user

A local account belongs to this Windows installation, rather than being a Microsoft online sign-in. For this guide, use a generic name such as Browse. Keep your normal account for personal email, banking, shopping, and cloud storage. Keep a working administrator account for maintenance, but do not browse day to day as an administrator.

  1. 1. Start from an administrator account

    Back up important files first. This is a change to an already working Windows 11 PC, not a workaround for Windows installation or Microsoft account requirements.

  2. 2. Add the user

    Open Start → Settings → Accounts → Other users. Under Add other user, choose Add account. Microsoft's support article sometimes writes the page name as “Other user.”

  3. 3. Choose local, not online

    Select I don't have this person's sign-in information, then Add a user without a Microsoft account. Enter Browse as the user name and follow the on-screen prompts. If Windows asks for a password, use one you keep privately; never put it in a note on the PC or a public page.

  4. 4. Check the account type

    On the same Other users page, expand Browse. Next to Account options, select Change account type. Choose Standard User rather than Administrator, then OK. The Microsoft article confirms the dropdown but does not spell out every localized label; select the non-administrator type.

  5. 5. Open the new workspace

    Sign out and sign in as Browse once. Do not connect it to Microsoft, OneDrive, a work/school account, or browser sync. If an app asks to add an account to Windows or all apps, stop rather than accepting. Install your chosen browser in this user's space before capturing the baseline.

These account-creation and account-type steps come from Microsoft’s user-account guide. Microsoft generally recommends a Microsoft account for convenience and sync; we deliberately choose local here for separation.

Important: one user is not one protected drive

Reboot-to-restore protects drives or partitions, not just Browse. If your normal account is on the same protected Windows drive, its new files and changes can be rolled back too. A dedicated spare PC is simpler and safer than freezing your everyday family or work PC. A standard user also does not hide activity from the administrator.

03Make reboot-to-restore work safely

A current-source correction

Reboot Restore Rx Freeware has been retired. Horizon DataSys now directs home/light-use customers to paid Reboot Restore Standard. Do not download an old “free Rx” copy from a mirror and assume it is current or supported. There is no verified current free Rx option in this guide. See the official retirement notice.

Before installing either tool

  1. Back up the whole PC and important files elsewhere. A baseline on the same disk is not a backup against disk failure, loss, or a bad setup. Make sure you know how to restore your backup. Disconnect the backup drive before configuring protected drives.
  2. Finish setup first. Create Browse, choose and update the browser, apply the privacy settings in section 6, and finish Windows updates. Restart until updates are complete. Do not sign into personal sites during setup.
  3. Check compatibility before paying or installing. Check your Windows release, hardware, disk layout, encryption, and the vendor's latest requirements. Do not install both restore products together.
  4. Know what is protected. Browser profiles, caches, downloads, and Desktop/Documents used by Browse must be on protected storage if you expect them to reset. Redirected folders, cloud copies, network drives, USB drives, and exclusions can survive a restart. Avoid them for this workspace.
  5. Use the administrator account only for maintenance. Set a separate password on the restore tool. Do not share that password with the browsing user. Follow the product's recovery instructions before you need them.

Encryption is a real stop sign

Horizon’s installation warning says BitLocker/device encryption can block its setup and describes turning it off. Do not casually remove disk encryption just to follow this guide: it protects data on a lost or stolen disk. Keep recovery information privately, and ask the vendor to confirm a supported setup for your exact PC. This guide does not claim either product is compatible with every encryption or Windows configuration.

Option A · Horizon DataSys

Reboot Restore Standard (the current successor)

The vendor describes local baseline protection, reset on reboot/logoff, and manual baseline updates. Its current pricing page lists US $48.85 per license, including one year of updates; its product page advertises a 14-day trial. This is not a free permanent license. Check current terms before choosing. Product details · Official pricing.

Option B · Faronics

Deep Freeze Standard

A paid product that calls protected mode Frozen and maintenance mode Thawed. The 2026 Standard manual describes a 30-day evaluation; a trial is not a permanent free license. No current checkout price is quoted here. Product details · 2026 manual (PDF).

A. Reboot Restore: setup without pretending old freeware is current

  1. Start at Horizon’s Standard product page and use its official trial/download route. Read the current installer and requirements for that edition. Do not substitute RollBack Rx (a different product) or old Rx Pro/freeware instructions.
  2. After the preparation above, sign into your administrator account, close your work, and run the official installer. Read the drive/partition selection carefully: the intended Windows drive and Browse profile storage must be covered, while backup storage must not be included by mistake.
  3. Installation detail not confirmed: the current public pages we checked do not provide a complete, Standard-specific Windows 11 installer-screen walkthrough. We therefore do not invent button names or tell you which partitions to tick blindly. If the installer is unclear, stop and use Horizon support. The Deep Freeze route below has a verified current step-by-step manual.
  4. Once installed, open the tray application and use its administrator password. In Restore Settings, use automatic restore every time the computer boots up, then apply. These setting names are confirmed in Horizon's current patch-management instructions. Test the reset before relying on it.

A. Reboot Restore: keep Windows and browsers updated

A frozen old browser is not safe simply because it is old in the same way every morning. Set a regular maintenance reminder outside the protected PC, and update promptly when security fixes arrive. Do not rely on an update that vanishes at the next restart.

  1. Start clean. Restart while automatic restore is still active, before opening any personal sites. Horizon explicitly recommends restoring the last baseline first so guest data is not captured.
  2. Open the Reboot Restore tray icon, enter the tool's administrator password, open Restore Settings, choose Restore On Demand, then Apply. This pauses the automatic reset so updates can survive multiple reboots. It is the usual maintenance route—not a full shutdown of the protection engine.
  3. Install Windows updates and browser updates; restart as many times as required. Use only official installers/updaters. Do not do everyday browsing during this maintenance session.
  4. When updates are complete, return to Restore Settings and set automatic restore back to Every time the computer boots up. Before restarting, open Update Baseline → New Baseline. That commits the clean, updated state. This order follows Horizon’s October 27, 2026 patch-management article.
  5. Restart and verify that protection is active and the new browser version remains. Run the harmless reset test below again.

Sources: current patch-management steps and baseline guidance. The older baseline article gives a different order for the final two settings; this guide follows the newer patch-management article and avoids a reboot between them.

Full disable is different

Horizon also documents a full protection-off route for major Windows feature upgrades or difficult changes. It removes saved backup baselines and is not the normal patching procedure. Do not copy commands with example passwords from the internet. Use Scenario 3 in the official guide with vendor help for your exact edition, then re-enable, re-baseline, and test. No unverified “unlock snapshot” menu path is supplied here.

B. Deep Freeze Standard: install and freeze

The following names are checked against the 2026 Deep Freeze Standard manual, System Requirements, installation, logon, Boot Control and Password sections. That manual lists Windows 11 up to 25H2 and requires 10% free disk space. If your Windows release is newer, get current compatibility confirmation first; do not assume.

  1. Get the installer through Faronics’ official Standard product page. After finishing Windows/browser setup and backups, close applications and sign into the administrator account. Open DFStd.exe.
  2. Select Next, read the license terms, choose I agree to the terms in the License Agreement, then Next.
  3. Enter a valid license key, or deliberately select Use Evaluation for the limited trial. Select Next. Buying a license is a separate decision; nothing is purchased by following this page.
  4. On the drive list, choose the drives you intend to Freeze, then Next. Include the storage that actually holds Browse's profile. Do not confuse a drive letter with a user account. External hard drives are Thawed by default; removable media and network drives are not protected by Deep Freeze.
  5. The next stage offers Create ThawSpace. A ThawSpace keeps files across reboots. For this minimal browsing setup, do not create one for browsing files or profiles. Existing ThawSpaces may be retained by default, so inspect the setup rather than assuming nothing survives.
  6. Save/close everything and select Install. The manual says the computer restarts immediately when installation completes.
  7. Open the Deep Freeze controls with Shift + double-click its system-tray icon, or Ctrl + Alt + Shift + F6. On first login, if no tool password has been set, the manual says to leave the field blank and choose OK. Immediately use the Password tab to set and confirm a strong tool password, then OK. This is the Deep Freeze password, not necessarily your Windows password.
  8. In Boot Control, choose Boot Frozen. Select OK and restart, or Apply and Reboot. Confirm the tray status is Frozen. The selection controls the next boot; changing it does not instantly change the running session.

Installation caveat: the Faronics manual asks for background utilities and antivirus to be disabled for installation. This guide does not recommend turning off security tools casually or browsing unprotected. If that is necessary on your PC, get Faronics’ current guidance, keep the interruption brief, and restore protection immediately. Do not disable antivirus permanently.

B. Deep Freeze: thaw, update, refreeze

  1. Restart into a clean Frozen baseline first. Do not carry an ordinary browsing session into maintenance.
  2. Open Deep Freeze with Shift + double-click or Ctrl + Alt + Shift + F6, enter its password, then go to Boot Control → Boot Thawed. Choose OK and restart (or Apply and Reboot).
  3. Verify it is now Thawed. New changes are permanent while Thawed. Complete Windows and browser updates, including any further restarts. Stay out of personal accounts.
  4. Check the new versions and settings. Reopen Deep Freeze, choose Boot Frozen, then Apply and Reboot (or OK and restart). Verify Frozen status again.
  5. Deep Freeze keeps the updated disk state when you freeze it again; there is no separate “New Baseline” button in this workflow. Do not mix up the two products' instructions. Repeat the reset test.

Verified in Faronics’ Freeze/Thaw article and the manual's Boot Control and permanent-software-change sections. To remove Deep Freeze later, first boot Thawed and follow the manual's uninstall instructions using the installer. Do not simply remove its files.

The update steps inside Windows and the browser

  • Windows 11: while maintenance is active, open Start → Settings → Windows Update, then select Check for Windows updates (Microsoft’s wording; the button text can vary by build). Install available updates with Download & install if shown, and restart when requested. Recheck until required updates have finished. Microsoft’s update instructions.
  • Tor Browser: when it offers an update, open the main menu ≡ → Update available – restart now, wait for installation, and let the browser restart. Finish this while the disk is Thawed or restore is On Demand. Official Tor update steps.
  • Mullvad Browser or Brave: finish their official update prompts during maintenance, or use the current official installer for your selected browser. The sources checked here do not confirm a current Windows menu-by-menu updater path for both, so no guessed “About” path is printed. Record the updated version before refreezing, then confirm it survives a restart.

Prove it with a harmless reset test

  1. Confirm automatic restore/Frozen status. Sign into Browse.
  2. Create a harmless text file named reset-test.txt on Browse's Desktop. Do not use an important document as the test.
  3. Use Restart, not just close the browser, lock the screen, or sleep. Sign into Browse again.
  4. The test file should be gone. Your installed browser and clean settings should still exist. If not, stop and check protected drives and restore state before browsing.
  5. After every maintenance session, repeat the test and also check that updates remained. One test proves only that location reset—it does not prove forensic erasure, anonymous networking, or that every disk is protected.

Files you want to keep need a deliberate exception

Assume new files on protected drives will disappear at the next reset—even files in another user account. Copying to an unprotected device can preserve them, but also preserves a trail. For this browsing workspace, the simplest habit is not to keep files at all. Never store the only copy of anything important here.

04Choose a browser—and resist the urge to decorate it

You do not need all three. Start with Tor Browser if you want its integrated network anonymity protections, or Mullvad Browser with a properly configured VPN if that matches your goals. Brave is a more conventional everyday-browser option with built-in tracking defenses; do not treat it as an identical anonymity substitute.

Mullvad Browser: reduce fingerprinting without the Tor network

  1. Sign into Browse and download the Windows installer from the official Mullvad Browser page. It is free whether or not you use Mullvad VPN. The browser itself is not a VPN and does not mask your IP on its own.
  2. Open the downloaded .exe. Choose Standard installation and keep the default location inside your user folder. Mullvad's November 17, 2026 instructions warn that changing the destination to C:\Program Files can break updating/uninstalling. Do not follow an old “always install it on the Desktop” guide. Current Windows installation steps.
  3. Launch it from its Desktop or Start-menu shortcut. Keep its built-in private mode, fingerprint defenses, and bundled blockers. Mullvad says private mode is on by default; cookies are discarded after the last private window closes. Bookmarks and extension settings can still persist. Downloaded files do not magically vanish because a private window closes.
  4. Keep the default browser configuration. Do not install more extensions, remove built-in protections, spoof your user-agent, edit hidden preferences, or pile on “privacy tweaks.” The goal is to resemble other users of the same browser, not create a one-of-a-kind setup.
  5. If you use a VPN, connect the VPN app before opening sites, and verify its connection. Merely opening Mullvad Browser is not enough. Its default DNS-over-HTTPS setup and an optional VPN-specific DNS change are documented in the installation guide; do not copy a DNS change unless it matches your actual VPN configuration.

Mullvad’s hard facts explain its private mode, bundled defenses, three security levels, and letterboxing. Keep Standard initially for a usable baseline; Safer or Safest intentionally disable more features and can break sites. The source confirms those levels, but a current Windows click-by-click path to the selector was not verified for this guide. Do not edit hidden preferences to imitate it.

Tor Browser: browser protections plus the Tor network

  1. Download only from the official Tor Project download route. Choose the Windows .exe, open it, and complete the installation wizard. Tor recommends verifying the signature; its download/install guide links the verification steps. Keep the installation in Browse's protected user storage. Windows instructions.
  2. Launch Tor Browser and choose Connect for an ordinary connection. If Tor is blocked where you are, use the official connection-assistance/bridges guidance, not a random proxy list. First-launch help.
  3. Leave the supplied add-ons and browser defenses intact. Do not add extensions or themes, and do not copy your regular browser profile into it. Tor strongly discourages added add-ons because they can undermine its protections. Official add-on guidance.
  4. The default Security Level is Standard. Safer disables JavaScript on non-HTTPS sites and limits some fonts/media; Safest disables JavaScript by default on all sites and more features. Use these built-in levels if needed rather than inventing your own patchwork. Official security-level guide.
  5. Path caveat: the current desktop security-level guide illustrates the controls in screenshots but does not spell out the full desktop click sequence in its text. Follow those official pictures for your installed version; this page does not guess a version-specific menu path.
  6. When you need a clean browser identity during a session, Tor's main menu ≡ → New Identity closes tabs/windows, clears private information such as cookies/history, and uses new circuits. Save any work first. New Tor Circuit for this Site is different: it changes that site's route but does not clear private information. Neither undoes a personal login already recorded by a service. Managing identities.

Window size and letterboxing: a gentle rule, not a scary myth

Mullvad Browser and Tor Browser use letterboxing: the gray margins around web content group many users into shared page sizes. For a beginner, leave the opening window at its usual size and do not maximize/fullscreen or resize it just to eliminate those margins. Leave letterboxing on.

Importantly, modern letterboxing also helps when a window is resized or maximized. An accidental resize does not instantly reveal your identity. The aim is to avoid unnecessary customization, not to panic about one click. This is verified in Mullvad’s letterboxing explanation and Tor’s current fingerprinting documentation. This letterboxing advice applies to those browsers; it is not a claim that Brave uses the same mechanism.

Brave: built-in blocking and fingerprint randomization

  1. Download Brave from Brave’s official download page and install it in the Browse workspace. Do not import personal passwords, history, or bookmarks, and do not enable sync with your personal devices.
  2. Keep Shields up. To review global controls, use Main menu → Settings → Shields. For one site, click the lion icon at the right of the address bar. The site panel's Advanced controls are optional; leave defaults initially. Verified global/per-site paths.
  3. Brave blocks cross-site cookies and trackers and randomizes fingerprintable browser features by default. Do not look for a “Strict fingerprinting” mode: Brave retired it starting with version 1.64. An Aggressive ad/tracker setting is not the old Strict fingerprinting mode. Shields protections · Official retirement explanation.
  4. For less browser telemetry, open Settings → Privacy and Security → Data Collection, and turn off the offered crash logs, privacy-preserving product analytics (P3A), and daily usage ping. Those are documented controls, unlike random hidden-flag recipes. Current Brave instructions.
  5. Do not enable Rewards or extra services just for this project. Do not add a collection of extensions. Brave's normal window does not hide your IP; an ordinary private window is not a network anonymity tool either.

Brave Tor windows are not Tor Browser

Brave itself says its Private Windows with Tor are regular private windows using Tor as a proxy, and do not implement most Tor Browser privacy protections. Use Tor Browser for the Tor route in this guide. Read Brave’s warning.

Across all choices: keep the software updated, refuse unnecessary site permissions, and do not sign into personal accounts. If a site does not work, weigh whether you need it in this workspace instead of weakening everything globally. Security/usability settings change; check the linked official guide before changing them.

05Choose Tor or a VPN for the IP-address job

Route 1: Tor Browser by itself

Tor Browser sends its browsing traffic through Tor relays, so a destination normally sees a Tor exit address instead of your home IP. It is free. It does not automatically send Windows updates, another browser, a download manager, or every other program through Tor. Only applications configured for Tor are covered. Tor’s own limits.

Trade-offs: relay routing can be slower, and sites can identify Tor exits and block them, present CAPTCHAs, or lock accounts for unusual locations. Do not use a personal bank login as a test. Speed explanation · Site blocking and account warnings.

Route 2: a trustworthy VPN app plus Mullvad Browser (or Brave)

  1. Choose a VPN provider deliberately. Read its privacy policy, logging claims, supported Windows setup, and independent audit information if available. A VPN is not automatically trustworthy because it says “private.”
  2. Install and configure its official Windows app while restore is in maintenance mode or before your first baseline. Connect it before browsing. Some apps have split tunneling or exclusions, so do not assume every program is covered.
  3. Use the provider's official connection check to confirm the intended public IP and DNS behavior. If it offers a kill switch or leak protection, follow that provider's current guide and test it. This page does not invent one universal VPN menu.
  4. If the VPN disconnects unexpectedly, stop browsing until you know whether traffic is blocked or falling back to your ordinary connection. A browser extension alone may cover only the browser; it is not necessarily equivalent to a full VPN app.

A VPN encrypts traffic to its server; the site then sees the VPN's exit IP. This shifts trust from your internet service provider to the VPN operator. It does not remove cookies, undo logins, or automatically stop fingerprinting. Performance varies, and VPN exit addresses can also trigger site checks or restrictions. Mullvad explains both the tunnel and the trust trade-off.

Do not stack tools carelessly

More layers do not automatically mean more privacy. The Tor Project generally does not recommend combining a VPN and Tor unless you are an advanced user who knows how to configure both without compromising privacy. For this beginner setup, choose one route and understand it first.

Keep HTTPS

Tor or a VPN is not a reason to ignore a browser certificate/security warning. HTTPS still protects the connection to the site. A VPN tunnel ends at the VPN, and Tor traffic to ordinary websites exits the Tor network. Do not send sensitive information to plain HTTP sites.

06Turn down Windows data sharing

Do this before the first baseline, or during a deliberate maintenance session. Check settings while signed in as Browse; some controls are per-user and others need the administrator. Recheck after major updates.

The following are the Windows 11 paths stated by Microsoft's official support pages checked on November 25, 2026. Labels can differ by update, language, or organization policy. If a page is missing, use Settings search and the linked official article; do not invent a replacement registry tweak. A missing or managed switch is not proof that collection is off.

Diagnostic data / telemetry

Keep required; decline optional

Start → Settings → Privacy & security → Diagnostics & feedback. Under Diagnostic data, turn off optional diagnostic data (or choose the required-only option shown). Microsoft says Windows still sends required diagnostic data; this is not a “zero telemetry” switch. Optional data can include browsing/activity details and more error information. The support article confirms the page and categories, not one universal switch label for every build. Microsoft’s diagnostic-data guide.

Advertising ID

Stop apps using this Windows ad identifier

Start → Settings → Privacy & security → General. Turn off Let apps show me personalized ads by using my advertising ID. This does not remove all ads, stop every tracker, or erase profiles already held by an advertiser. Microsoft notes that turning it back on resets the ID. Microsoft’s General privacy settings.

Location

Decline location access you do not need

Start → Settings → Privacy & security → Location. As administrator, turn Location services off if you do not need device location. For Browse's own account, turn Let apps access your location off. Microsoft says the device-level setting may not be visible to non-administrators. Some desktop apps/websites can still infer location by IP address or other means; Windows' toggle is not an IP-hiding tool. Microsoft’s location controls and limitations.

Activity history

Stop storing the Windows activity history described here

Start → Settings → Privacy & security → Activity history. Switch Store my activity history on this device off. If you want to remove existing entries, next to Clear activity history for this account, select Clear history. This does not clear a browser's own history or a website's logs. Microsoft’s activity-history instructions.

Two changes in Windows guides worth knowing about

  • Microsoft says Tailored experiences is being replaced by Personalized offers on newer versions. The diagnostics article still gives a Tailored experiences path. This page does not guess the current Personalized offers path; use the official link from the diagnostics article for your build if you want to review it.
  • Microsoft says sending activity history to Microsoft was deprecated for Windows 11 22H2/23H2 with the January 23, 2024 update. Do not hunt for an old Send my activity history to Microsoft switch that may no longer exist. Update Windows if you still see legacy options.

Keep security on. These settings are not a recommendation to disable Defender, Windows Update, firewall protections, or every Windows service. Turning off security to save a little data can undermine the whole project.

07Use it like a clean reading desk

  1. Start in Browse, not your administrator or personal user. Confirm the reset tool is active. For the VPN route, connect and verify it first; for Tor, browse inside Tor Browser.
  2. Never sign into personal accounts on this user. Keep email, banking, social accounts, shopping, password sync, and cloud storage in the separate personal workspace. That is this guide's separation rule—not a claim that a Tor login reveals your home IP. Logging in tells the service which account you are.
  3. Do not provide identifying details in forms. A private connection cannot make a real email address, telephone number, or identifying story anonymous. Avoid reusing identifying usernames or posting habits as well.
  4. Do not import or sync personal browser data. Keep the baseline free of saved passwords, personal bookmarks, cookies, and accounts. Do not use the machine to draft sensitive personal documents unless you understand where every copy is stored.
  5. Be careful with downloads. Do not run unknown programs or open untrusted documents in another app expecting Tor to protect that app. The Tor Project warns that documents downloaded through Tor (especially DOC and PDF files opened in another app) can load internet resources outside Tor and reveal your real IP. Do not ignore Tor Browser’s warning before opening one. Do not torrent over Tor.
  6. End with a real restart. Closing a tab, locking the screen, signing out, or sleeping is not the reboot test. Some tools can reset at logoff, but this setup explicitly relies on a verified reboot reset.
  7. Maintain the baseline. Make updates in a clean maintenance session. Never save a new baseline after a normal session: that could preserve the very cookies, files, or malware you intended to discard.

These habits put the Tor Project’s best practices and EFF’s tracking explanation into a deliberately simple routine.

08What this cannot promise

No perfect anonymity

The Tor Project explicitly says perfect anonymity is generally impossible, even with Tor. This is a privacy-improvement project, not a guarantee. If your safety depends on not being identified, do not treat this beginner setup as a complete threat model. Read Tor’s warning.

  • It does not erase remote records. A website, advertiser, account provider, VPN, internet provider, or network operator may retain information it already received. Rebooting your disk cannot recall it.
  • Your ISP still exists. It knows your subscription and can observe connection timing and traffic volume. A correctly working VPN normally hides destinations from the ISP by showing the VPN connection instead; Tor normally shows a connection to Tor rather than the final destination. Neither makes your connection disappear, and sophisticated traffic analysis is outside this guide.
  • Logins and behavior link activity. An account login identifies that account. Reused handles, distinctive writing, timing, and information you volunteer can also connect sessions. Changing IP or resetting cookies does not undo those choices.
  • It is still Windows. A local Browse account does not remove the operating system's required data flows. A Microsoft account signed into another Windows user or added to an app is not “unlinked” by creating Browse. Windows, installed software, administrators, and device management remain part of what you must trust.
  • Malware can act before reboot. It can steal data during the session. A compromised baseline, unprotected drive, firmware problem, or other persistence outside the restored area is not solved merely by rebooting. Do not substitute a restore product for patching, security tools, or careful downloads.
  • Rollback is not secure erasure or encryption. These products restore a usable state. This guide makes no promise against forensic recovery, physical access, theft of the disk, or copies outside protected storage. Windows encryption and backups solve different problems.
  • A separate user is not a separate machine. It helps prevent accidental mixing; it is not a hardened virtual machine or a barrier against the system administrator or every exploit. The computer's hardware and network may remain recognizable.
  • Site compatibility is not guaranteed. Stronger defenses can break video, sign-ins, forms, or entire sites. Some sites block Tor or VPN exits. You must choose a privacy/convenience balance rather than expect a tool to make every site work anonymously.

Sources: Tor’s anonymity limitations, Brave’s monitoring warning, Microsoft’s required diagnostic data, VPN trust explanation, and the vendors' restore scope in their manuals/product pages.
