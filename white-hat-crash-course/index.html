1. Ethics and legal rules (read first)

The one rule: Only hack systems you own or have written permission to test. Everything else can be a crime.

Your ticks are saved only in this browser.

  • justice.gov
  • DOJ policy on CFAA cases justice.gov
  • CISA coordinated vulnerability disclosure cisa.gov

2. Setup: free tools

All free to download. Install in this order.

ToolWhat it is
VirtualBoxRuns a whole separate computer (a VM) inside yours — keeps practice isolated
Kali LinuxLinux made for security testing, with hundreds of tools preinstalled; run it in VirtualBox
Burp Suite CommunitySits between your browser and a website so you can see and change requests (free edition)
NmapFinds which devices and ports are open on a network
WiresharkRecords network traffic so you can read it packet by packet
PythonProgramming language for writing your own tools
CyberChefIn-browser tool to decode, encode, and convert data (great for CTFs)
Ghidra (optional)Takes programs apart to see how they work (reverse engineering)

Use Firefox or Chrome as your browser. Nmap, Wireshark, Burp and Python already come with Kali.

3. Roadmap in 5 phases

Time estimates assume about 1 hour a day and are rough. Everything listed is free unless marked.

Phase 1: Networking and Linux (2 weeks)

  • Linux Journey — learn Linux basics linuxjourney.com
  • OverTheWire Bandit — Linux command line as a game overthewire.org
  • Cisco Networking Basics (free course) netacad.com
  • Professor Messer Network+ videos (free) professormesser.com

Phase 2: Core attacks and web hacking (2 weeks)

  • PortSwigger Web Security Academy — free web hacking labs portswigger.net
  • OverTheWire Natas — web security wargame overthewire.org
  • OWASP Juice Shop — deliberately hackable practice site owasp.org
  • Cisco Introduction to Cybersecurity (free + badge) netacad.com

Phase 3: Hands-on labs and CTFs (2–3 weeks)

  • picoCTF — beginner challenges (Carnegie Mellon) picoctf.org
  • TryHackMe — free rooms (full paths are paid) tryhackme.com
  • Hack The Box — free tier (some content paid) hackthebox.com
  • Hack The Box Academy — free starter modules academy.hackthebox.com
  • VulnHub — free vulnerable VMs to run in VirtualBox vulnhub.com
  • CTFtime — calendar of upcoming CTF competitions ctftime.org

Phase 4: Scripting (1–2 weeks, overlaps)

  • Python for Everybody — free course py4e.com
  • Automate the Boring Stuff with Python — free to read online automatetheboringstuff.com

Phase 5: First real-world work (ongoing)

Start with a vulnerability disclosure program (VDP: no money, lower pressure), then a beginner-friendly bug bounty. Read the scope twice before you test.

  • HackerOne program directory hackerone.com
  • Bugcrowd bugcrowd.com
  • Intigriti intigriti.com

4. Cheat sheet (lab use only)

Run these only in your own VMs, a lab, or a CTF target you're allowed to hit.

Recon
Find out what's there before attacking: hosts, ports, services, versions.
Enumeration
Dig into each service for users, folders, and versions.
Exploitation
Use a weakness to get access.
Privilege escalation
Go from a normal user to admin or root.
Common web bugs
SQL injection, XSS (injecting scripts), broken access control, IDOR (changing an ID to see someone else's data).
Flag
In a CTF, the secret text you find to prove you solved it.
CommandWhat it does
nmap 10.10.10.5Scan the 1,000 most common ports on a lab machine
nmap -sV 10.10.10.5Also detect service versions
nmap -p- 10.10.10.5Scan all 65,535 ports (slower)
nmap -sC -sV -oN scan.txt 10.10.10.5Default scripts + versions, save to a file
pwd / ls -la / cd folderWhere am I / list all files / move into a folder
cat file.txtPrint a file
grep -r "password" .Search all files here for a word
find / -name flag.txt 2>/dev/nullFind a file anywhere, hide errors
whoami / idWhich user am I
sudo -lWhat I'm allowed to run as admin
chmod +x script.shMake a file runnable
ip aShow my IP addresses
man nmapRead the manual for any command

Full Nmap manual: nmap.org/book/man.html

6. Give back

Report bugs the right way

  • HackerOne hackerone.com
  • Bugcrowd bugcrowd.com
  • Intigriti intigriti.com
  • disclose.io — find VDPs with safe harbor disclose.io

Report phishing and scams

  • FBI IC3 — report internet crime ic3.gov
  • APWG — forward phishing to reportphishing@apwg.org apwg.org
  • Google Safe Browsing — report a phishing site safebrowsing.google.com
  • FTC — report fraud reportfraud.ftc.gov

Join the community

  • OWASP local chapters (free meetups) owasp.org

Also look for a local DEF CON group (DCxxx, named after your area code) and the official Discord servers for TryHackMe, Hack The Box, and picoCTF, linked from their sites.
