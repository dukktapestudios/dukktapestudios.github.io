NETSPACE — HOW TO PLAY

The internet is the universe. Every web address is a star system, generated from the address itself — the same address is always the same system.

Mouse — steer (aim dot pulls the nose)
W / S — throttle up / down · Shift — boost
A / D — roll
Left click (hold) — lasers · Right click (hold) — mining beam on target
T — target next asteroid · Y — target next pirate
F — dock (near station) / use gate beacon
N — nav computer: type any URL to plot a jump
M — explored systems log · H — this help

Mine ore, dock, sell (prices differ per system), buy upgrades. Pirates lurk near asteroid belts. Fly into a jump gate to travel to another site. Die and you respawn at the station without your cargo.
